End-to-End E-Surveillance System Architecture

How Scanalitix ingests, processes, and acts upon millions of daily video feeds and alerts across thousands of remote sites.

Layer 1

Edge & Ingestion Layer

IP Cameras, Drones, IoT Sensors, and Edge Gateway devices stream RTSP/WebRTC feeds. Local Edge compute boxes perform lightweight object detection (YOLO tiny) to reduce bandwidth before transmitting compressed event payloads to the central cloud.

Layer 2

Event Streaming & Ingestion Backbone (Apache Kafka)

High-throughput Kafka clusters ingest millions of telemetry data points, frame metadata, and alert events. Topics are partitioned by site ID and camera ID to guarantee strict ordering and horizontal scalability.

Layer 3

Microservices Processing & AI Inference Engine

Spring Boot reactive microservices handle VMS control, CMS monitoring, and FSM dispatch. Deep learning worker pods (TensorFlow/PyTorch with TensorRT on GPU nodes) consume Kafka streams for real-time anomaly detection, facial recognition, and ANPR.

Layer 4

Storage, SLA Escalation & Operator Command Center

Time-series databases (TimescaleDB/InfluxDB) store metrics, object storage (S3/MinIO) holds video snippets, and Redis handles fast alert caching. SLA engines automatically trigger escalation workflows and dispatch field engineers via FSM mobile apps.

Pattern 1: Kafka-Based Event-Driven Microservices for Millions of Alerts

Async Pub-Sub Topology

Why Kafka? Decouples high-volume camera ingestion from heavy AI inference and database persistence. If GPU pods lag behind during spike traffic, Kafka buffers events cleanly without crashing the camera stream ingestors.

Pattern 2: Orchestration-Based SAGA Pattern (Incident & FSM Dispatch)

Distributed Transactional Flow

Compensating Transactions: If an engineer fails to accept the dispatch within the SLA window, the orchestrator triggers a compensating rollback transaction to re-assign the ticket to the next available team.

Pattern 3: Edge-Cloud Hybrid AI Pipeline

Distributed Inference

Edge Node (Local Box): Runs YOLOv8 tiny model directly on camera RTSP feed to detect PPE violations or unauthorized intruders locally with <15ms latency.

Cloud Center: Heavy models (Facial recognition databases, LLM incident report generation, quarterly model retraining) run in centralized AWS/Azure Kubernetes clusters fed by compressed JSON event metadata and video clips.

SurveillanceAlertProducer.java (Spring Boot Kafka) 
@Service
public class SurveillanceAlertProducer {

    private final KafkaTemplate<String, SurveillanceAlertEvent> kafkaTemplate;
    private static final String TOPIC = "scanalitix-ai-alerts-v1";

    public SurveillanceAlertProducer(KafkaTemplate<String, SurveillanceAlertEvent> kafkaTemplate) {
        this.kafkaTemplate = kafkaTemplate;
    }

    public void publishAlert(String siteId, String cameraId, String anomalyType, double confidence) {
        SurveillanceAlertEvent event = new SurveillanceAlertEvent(
            UUID.randomUUID().toString(),
            siteId,
            cameraId,
            anomalyType,
            confidence,
            Instant.now()
        );

        // Partition by siteId to ensure sequential ordering per camera site
        CompletableFuture<SendResult<String, SurveillanceAlertEvent>> future = 
            kafkaTemplate.send(TOPIC, siteId, event);

        future.whenComplete((result, ex) -> {
            if (ex == null) {
                log.info("Alert published successfully for site: {} offset: {}", siteId, result.getRecordMetadata().offset());
            } else {
                log.error("Failed to publish alert for site: {}", siteId, ex);
            }
        });
    }
}
edge_inference_worker.py (OpenCV & YOLOv8) 
import cv2
from ultralytics import YOLO

class EdgeSurveillanceInference:
    def __init__(self, model_path="yolov8n.pt", stream_url="rtsp://camera-feed"):
        self.model = YOLO(model_path)
        self.cap = cv2.VideoCapture(stream_url)

    def process_stream(self):
        while self.cap.isOpened():
            ret, frame = self.cap.read()
            if not ret:
                break
            
            # Run inference on edge GPU/CPU
            results = self.model(frame, stream=True, conf=0.75)
            for r in results:
                boxes = r.boxes
                for box in boxes:
                    cls_id = int(box.cls[0])
                    class_name = self.model.names[cls_id]
                    if class_name in ["person_without_helmet", "unauthorized_vehicle"]:
                        # Trigger local alert packet
                        self.emit_alert(class_name, float(box.conf[0]))

    def emit_alert(self, anomaly_type, confidence):
        print(f"[EDGE AI ALERT] Detected {anomaly_type} with confidence {confidence:.2f}")

Apache Kafka

Analogy: The Magical Conveyor Belt at a Pizza Factory 🍕

Imagine 10,000 security cameras are like chefs shouting pizza orders all at once. If the delivery drivers had to listen to everyone directly, total chaos! Instead, all orders are placed onto a magic conveyor belt (Kafka). The conveyor belt keeps them in exact order. Workers (Microservices) can grab orders off the belt whenever they are ready, so nothing gets lost even if the oven temporarily slows down!

Instead of one overworked chef cooking, cleaning, and delivering, you have separate specialists: Sushi Chef, Drink Master, and Delivery Rider. If the delivery rider gets stuck in traffic, a manager (SAGA Orchestrator) steps in to cancel the dispatch and hand the food to someone else. Everyone does one job really well!

Director & CTO Level Interview Questions & Master Answers

High-stakes strategic questions covering scaling millions of alerts, failure handling, ROI, and AI governance.

Q1 How would you architect Scanalitix to handle 10 million daily alerts across 5,000 active remote enterprise sites without dropping critical security incidents?

Architectural Answer: "At this scale, synchronous HTTP REST calls fail. I implement a decoupled edge-to-cloud architecture:

  • Edge Filtering: Edge boxes perform local YOLOv8 inference so 90% of normal video frames are discarded locally, transmitting only compressed event JSON payloads upstream.
  • Kafka Partitioning: Ingest through Kafka clusters partitioned by Site ID and Camera ID, guaranteeing ordered ingestion and horizontal consumer scaling.
  • Backpressure & Priority Queues: High-priority intrusion alerts bypass standard batch analytics queues using dedicated high-priority Kafka topics and dedicated worker pods."

Q2 How do you address AI model drift and guarantee compliance/governance in production video analytics?

CTO Level Answer: "Model drift is mitigated via continuous MLOps pipelines:

  • Shadow Deployments & Drift Metrics: We log inference confidence scores and operator overrides in TimescaleDB. If false-positive rates spike by >5%, an automated alert triggers.
  • Data Privacy & AI Governance: Implement automated face-blurring and anonymization pipelines on edge devices before storing snippets in S3, complying with GDPR and enterprise data privacy policies."

Q3 How do you handle stakeholder management when transitioning monolithic legacy surveillance systems to Scanalitix's modern microservices platform?

Director Level Answer: "I use the Strangler Fig pattern:

  • Incremental Migration: Wrap legacy RTSP streams with an API gateway, migrating non-critical sites (e.g., retail branches) to the new microservices platform first while keeping high-risk sites (e.g., defence perimeters) stable until validation.
  • Cross-Functional Alignment: Regular syncs with product managers, infrastructure leads, and security officers to define clear SLAs and risk mitigation matrices."
